# Tidegarden — playable build

Only the compiled pixel build lives here, published automatically
from a private source repository.

Play: https://patrickgod.github.io/tidegarden-play/

Work in progress — this is an early slice, not the game.

## AI disclosure

Parts of the art and audio in this build were produced with
generative AI tools and then processed, palette-constrained and
assembled by hand. Said plainly here because it is true, and
because a player deserves to know before they look.
